==================================================================
Release Notes for FINDZIP: Integratable Mapping Sample Application
==================================================================
This application is written in Visual Basic 6.0 Standard Edition.
It is designed as a simple demonstration of the Integratable Mapping
feature introduced in MapInfo 4.0.

Note: This application makes use of us_zips.tab, which is not 
      installed with the standard data.  Us_zips.tab is located 
      on your MapInfo Professional CD.

------------------------------------------------------------------
Contents
------------------------------------------------------------------
README.TXT	- this file

FINDZIP.VBP	- Visual Basic project file
FINDZIP.FRM	- Main form for application
FINDZIP.FRX	- Visual Basic internal file
		  contains copies of icons referenced by form

ARROW.ICO	- Selector tool icon
CHGVIEW.ICO	- Change View icon
CROSS.ICO	- Crosshair icon
HAND.ICO	- Grabber tool icon
INFOTOOL.ICO	- InfoTool icon
QUERY.ICO	- Query tool icon
ZOOMIN.ICO	- ZoomIn tool icon
ZOOMOUT.ICO	- ZoomOut tool icon

Note that the second group of files (FINDZIP.*) are the complete
sources for the application.  The icon files (third group) are
provided for use if the .FRX file gets damaged.  Note that more
icons are provided than were actually used in the application.
