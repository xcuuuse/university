Welcome to MapInfo Professional and the world of desktop mapping!  This
README file contains the following information about the Australian sample

MapInfo Professional:

2.  A description of the Australian abbreviation file installed with your 
    copy of MapInfo.

1.  DESCRIPTION OF THE SAMPLE DATA DIRECTORY

MAP_DATA \ AUSTRLIA\ SAMPLES:        All from Australian 'DATA' sample

The SAMPLES directory contains a specific set of sample data for Australia.
Some of the data are designed to work together which means the layers will 
overlay correctly, providing the capability to combine the data for various 
mapping needs.  Other sample data may not work together causing the 
appearance of mismatches in layer boundaries when combined. The reason 
some layers do not work together is because they are from different 
sources and scales and are designed for different mapping purposes. 

The SAMPLES Directory contains the following sample data for Australia:

*   Australian State boundaries.
*   Australian major highways.
*   Australian major rivers.
*   Australian State capital cities.
*   Sample Local Government Area boundary for Manly (Sydney).
*   Sample suburb boundaries for Sydney.
*   Sample postcode boundaries for Sydney.
*   Sample Census Collection District boundaries for Sydney.
*   Sample detailed streets for Sydney.
*   Sample detailed drainage for Sydney.
*   Sample town points for Sydney.
*   Sample feature points for Sydney.
*   Sample raster image for Sydney.
*   Sample customer database for Sydney.

To view the Australian sample data:

-   Run MapInfo Professional.
-   Select File > Open Workspace.
-   Choose one of the workspaces listed below:

    *   AUSTRLIA.WOR - Shows sample data for all of Australia. Use the 
        Zoom-In tool to zoom in and see different data layers.

    *   SYDNEY.WOR - Shows sample data for an area in Sydney. Use the 
        Zoom-In tool to zoom in and see different data layers.
      

2.  ABBREVIATION FILE

The MapInfo abbreviation file, MAPINFOW.ABB, is used to enhance address 
matching during geocoding.  An abbreviation file suitable for use in 
Australia is installed with the Australian sample data. This file should 
be placed in the MapInfo program directory.  The abbreviation file contains 
abbreviations for street types, prefixes and suffixes that are commonly 
used in the detailed street files supplied by MapInfo Australia.
