## Вопрос 1

**Задание.** Вычислить нечёткую мощность нечёткого множества `{<a,0.0>,<b,0.5>,<1,0.3>,<c,0.2>}`.

**Ответ.** `{<0,1.0>,<1,0.5>,<2,0.3>,<3,0.2>}`. Если в курсе «мощность» означает скалярную мощность, то ответ **1.0**.

**Решение.**
1. Нечёткая мощность по Заде (FGCount) — нечёткое число на множестве натуральных чисел. Степень для k равна наибольшему α, при котором в α-срезе не меньше k элементов.
2. Степени принадлежности по убыванию: 0.5, 0.3, 0.2, 0.0.
3. α-срезы дают: 1 элемент при α ∈ (0.3; 0.5], 2 элемента при α ∈ (0.2; 0.3], 3 элемента при α ∈ (0; 0.2].
4. Значит, FGCount(0) = 1.0, FGCount(1) = 0.5, FGCount(2) = 0.3, FGCount(3) = 0.2.
5. Скалярная мощность (σ-count, Де Люка–Термини) равна сумме степеней: 0.0 + 0.5 + 0.3 + 0.2 = 1.0.

**Источник.** В предоставленных файлах определения нет. Использованы открытые источники: Zadeh, определение FGCount и σ-count (arXiv:1301.6712, arXiv:2109.11227).

## Вопрос 2

**Задание.** Вычислить нечёткое пересечение нечётких множеств `{<a,0.2>,<b,1.0>,<c,0.5>,<d,0.0>}` и `{<a,0.7>,<b,0.3>,<c,0.5>,<d,0.8>}`:

- 1) `{<c,0.5>}`
- 2) `{<a,0.14>,<b,0.3>,<c,0.25>,<d,0.0>}`
- 3) `{<a,0.2>,<b,0.3>,<c,0.5>,<d,0.0>}`
- 4) `{<a,0.14>,<b,0.3>,<c,0.25>}`
- 5) `{<a,0.2>,<b,0.3>,<c,0.5>}`

**Ответ: 3.**

**Решение.** (A ∩ B)(x) = min(A(x), B(x)).
- a: min(0.2; 0.7) = 0.2
- b: min(1.0; 0.3) = 0.3
- c: min(0.5; 0.5) = 0.5
- d: min(0.0; 0.8) = 0.0

**Источник.** `Log_Osn.pdf`, стр. 59 (операции над нечёткими множествами).

## Вопрос 3

**Задание.** Вычислить нечёткое объединение нечётких множеств `{<a,0.2>,<b,1.0>,<c,0.5>,<d,0.0>}` ~U `{<a,0.7>,<b,0.3>,<c,0.5>,<d,0.8>}`:

- 1) `{<a,0.9>,<b,1.0>,<c,1.0>,<d,0.8>}`
- 2) `{<a,0.2>,<b,0.3>,<c,0.5>,<d,0.0>}`
- 3) `{<a,0.2>,<b,0.3>,<c,0.5>}`
- 4) `{<a,0.7>,<b,1.0>,<c,0.5>,<d,0.8>}`
- 5) `{<a,0.2>,<a,0.7>,<b,0.3>,<b,1.0>,<c,0.5>,<d,0.0>,<d,0.8>}`

**Ответ: 4.**

**Решение.** (A ∪ B)(x) = max(A(x), B(x)).
- a: max(0.2; 0.7) = 0.7
- b: max(1.0; 0.3) = 1.0
- c: max(0.5; 0.5) = 0.5
- d: max(0.0; 0.8) = 0.8

Вариант 1 — граничная сумма min(1, A+B), вариант 5 — просто сложенные пары без объединения по max.

**Источник.** `Log_Osn.pdf`, стр. 59.

## Вопрос 4

**Задание.** Вычислить нечёткую разность нечётких множеств `{<a,0.2>,<b,1.0>,<c,0.5>,<d,0.0>}` ~/ `{<a,0.7>,<b,0.3>,<c,0.5>,<d,0.8>}`:

- 1) `{<a,0.2>,<b,1.0>}`
- 2) `{<a,0.5>,<b,0.7>,<c,0.0>,<d,0.8>}`
- 3) `{<b,0.7>}`
- 4) `{<a,0.2>,<b,1.0>,<d,0.0>}`
- 5) `{<a,0.0>,<b,0.7>,<c,0.0>,<d,0.0>}`

**Ответ: 5.**

**Решение.** В курсе разность определена как (A // B)(x) = max(0, A(x) − B(x)).
- a: max(0; 0.2 − 0.7) = 0.0
- b: max(0; 1.0 − 0.3) = 0.7
- c: max(0; 0.5 − 0.5) = 0.0
- d: max(0; 0.0 − 0.8) = 0.0

Определение min(A, 1−B) здесь не подходит: оно дало бы b = 0.7, но a = 0.2, c = 0.5, и такого варианта среди ответов нет.

**Источник.** `Log_Osn.pdf`, стр. 59 (формула нечёткой разности).

## Вопрос 5

**Задание.** Вычислить нечёткую max-min-композицию нечётких отношений `{<<a,b>,0.2>,<<a,c>,0.5>,<<f,c>,0.1>}` ∘ `{<<b,d>,0.8>,<<c,d>,0.4>,<<c,e>,0.3>}`:

- 1) `{<<a,d>,0.4>,<<f,e>,0.1>}`
- 2) `{<<a,d>,0.4>,<<f,e>,0.1>,<<f,d>,0.1>,<<a,e>,0.3>}`
- 3)–5) варианты, где пара ⟨a,d⟩ повторяется с разными степенями (0.2, 0.4, 0.5 и т. п.), то есть значения не объединены по max (на фото текст мелкий, дословно не воспроизвожу).

**Ответ: 2.**

**Решение.** (R₁ ∘ R₂)(x,z) = max по y от min(R₁(x,y), R₂(y,z)).
- (a,d): max(min(0.2; 0.8), min(0.5; 0.4)) = max(0.2; 0.4) = 0.4
- (a,e): min(0.5; 0.3) = 0.3
- (f,d): min(0.1; 0.4) = 0.1
- (f,e): min(0.1; 0.3) = 0.1

**Источник.** `Log_Osn.pdf`, стр. 60 (формула композиции).

## Вопрос 6

**Задание.** Вычислить нечёткую дизъюнкцию (max({a}U{b})) нечётких предикатов A(x)=`{<a,0.2>,<b,0.7>,<c,0.5>}` и B(y)=`{<a,0.7>,<b,0.3>,<c,0.5>}`:

- 1) `{<<a,a>,0.7>,<<b,b>,0.7>,<<c,c>,0.5>}`
- 2) `{<<a,a>,0.7>,<<a,b>,0.7>,<<a,c>,0.7>,<<b,a>,0.7>,<<b,b>,0.7>,<<b,c>,0.7>,<<c,a>,0.7>,<<c,b>,0.7>,<<c,c>,0.5>}`
- 3) `{<a,0.2>,<b,0.7>,<c,0.5>,<a,0.7>,<b,0.3>}`

- 5) `{<a,0.7>,<b,0.7>,<c,0.5>}`

**Ответ: 4.**

**Решение.** Переменные разные (x и y), поэтому результат — предикат двух переменных C(x,y) = max(A(x), B(y)):

| a (0.2) | max(0.2;0.7)=0.7 | max(0.2;0.3)=0.3 | max(0.2;0.5)=0.5 |

| c (0.5) | 0.7 | max(0.5;0.3)=0.5 | 0.5 |

**Источник.** `Log_Osn.pdf`, стр. 60–61 (нечёткие предикаты, дизъюнкция). Правило «разные переменные дают предикат двух переменных» — вывод из определения, дословно в тексте его нет.

## Вопрос 7

**Задание.** Вычислить нечёткую конъюнкцию (a\*b) нечётких предикатов A(x)=`{<a,0.2>,<b,0.7>,<c,0.5>}` и B(x)=`{<a,0.7>,<b,0.3>,<c,0.5>}`:

- 1) `{<a,0.14>,<b,0.21>,<c,0.25>}`
- 2) `{<<a,a>,0.14>,<<a,b>,0.49>,<<a,c>,0.35>,<<b,a>,0.06>,<<b,b>,0.21>,<<b,c>,0.15>,<<c,a>,0.1>,<<c,b>,0.35>,<<c,c>,0.25>}`
- 3) `{<<a,a>,0.14>,<<a,b>,0.06>,<<a,c>,0.1>,<<b,a>,0.49>,<<b,b>,0.21>,<<b,c>,0.35>,<<c,a>,0.35>,<<c,b>,0.15>,<<c,c>,0.25>}`
- 4) `{<<a,b,c>,0.6>}`
- 5) `{<a,0.98>,<b,0.42>,<c,0.7>}`

**Ответ: 1.**

**Решение.** В этом вопросе у обоих предикатов одна и та же переменная x, поэтому операция выполняется поэлементно: C(x) = A(x) · B(x).
- a: 0.2 · 0.7 = 0.14
- b: 0.7 · 0.3 = 0.21
- c: 0.5 · 0.5 = 0.25

Вариант 3 был бы верным, если бы второй предикат был B(y) с другой переменной. На фото стоит именно B(x).

**Источник.** `Log_Osn.pdf`, стр. 60–61.

## Вопрос 8

**Задание.** Какая конорма двойственна для указанной треугольной нормы a\*b:

- 1) `min({a+b}U{1})`
- 2) ни одна из перечисленных
- 3) `1-a-b+a*b`
- 4) `max({0}U{1-a-b})`
- 5) `a+b-a*b`

**Ответ: 5.**

**Решение.** Двойственная конорма: S(a,b) = 1 − T(1−a, 1−b). При T(a,b) = a·b получаем S = 1 − (1−a)(1−b) = a + b − a·b.

**Источник.** `Log_Osn.pdf`, стр. 61 (конорма выражается через норму и отрицание).

## Вопрос 9

**Задание.** Какая норма двойственна для указанной треугольной конормы min({1}U{a+b}):

- 1) `min({1}U{a+b-1})`
- 2) `max({0}U{a+b-1})`
- 3) `max({0}U{a*b-a-b})`
- 4) `a*b`
- 5) `min({1}U{2-a-b})`

**Ответ: 2.**

**Решение.** T(a,b) = 1 − S(1−a, 1−b) = 1 − min(1; (1−a)+(1−b)) = 1 − min(1; 2−a−b) = max(0; a+b−1).

## Вопрос 14

**Задание.** Вычислить значение импликации Гёделя 0.5~>0.3.

**Ответ: 0.3.**

**Решение.** Импликация задаётся как A→B = sup{δ : A ⋆ δ ≤ B, δ ≤ 1}. Норма Гёделя — min. Условие min(0.5; δ) ≤ 0.3 выполняется при δ ≤ 0.3, значит супремум равен 0.3.

**Источник.** `Log_Osn.pdf`, стр. 62 (определение импликации), стр. 64 (список t-норм; min — «логическое произведение, импликация Гёделя»).

## Вопрос 20

**Задание.** Для какой нормы выполняется закон противоречия:

- 1) `min({a}U{b})`
- 2) `a*b/(a+b-a*b)`
- 3) `max({0}U{a+b-1})`
- 4) `a*b`
- 5) ни для одной

**Ответ: 3.**

**Решение.** Закон противоречия: T(a, 1−a) = 0 при любом a, где отрицание 1−a.
- min(a; 1−a) ≠ 0 (например, при a = 0.5 получаем 0.5)
- a(1−a)/(a + (1−a) − a(1−a)) = a(1−a)/(1 − a + a²) ≠ 0 (норма Хамахера)
- max(0; a + (1−a) − 1) = max(0; 0) = **0** при любом a
- a(1−a) ≠ 0

**Источник.** Отрицание 1−A: `Log_Osn.pdf`, стр. 60. Сам закон в файлах не приведён; проверено подстановкой.

**Задание.** Для какой конормы выполняется закон исключённого третьего:

- 1) `max({a}U{b})`
- 2) `(a+b)/(1+a*b)`
- 3) ни для одной
- 4) `min({1}U{a+b})`
- 5) `a+b-a*b`

**Ответ: 4.**

**Решение.** Закон исключённого третьего: S(a, 1−a) = 1 при любом a.
- max(a; 1−a) < 1 (при a = 0.5 получаем 0.5)
- (a + 1 − a)/(1 + a(1−a)) = 1/(1 + a(1−a)) < 1 (сумма Эйнштейна)
- min(1; a + (1−a)) = min(1; 1) = **1** при любом a
- a + (1−a) − a(1−a) = 1 − a(1−a) < 1

**Источник.** Отрицание 1−A: `Log_Osn.pdf`, стр. 60. Сам закон в файлах не приведён; проверено подстановкой.

## Вопрос 22

**Задание.** Каково значение максимума множества (0;1):

- 1) 1
- 2) 0
- 3) 2
- 4) 0.99
- 5) не определено

**Ответ: 5.**

**Решение.** Максимум — наибольший элемент, принадлежащий множеству. Интервал (0;1) не включает 1, а для любого числа x < 1 найдётся большее число (x+1)/2, тоже лежащее в интервале. Наибольшего элемента нет, максимум не определён.

**Источник.** В предоставленных файлах определения нет, это общий курс математического анализа.

## Вопрос 23

**Задание.** Каково значение точной верхней грани множества (0;1):

- 1) 1
- 2) не определено
- 3) 2
- 4) 0.99
- 5) 0

**Ответ: 1.**

**Решение.** Точная верхняя грань (sup) — наименьшая из верхних границ множества. Для (0;1) верхние границы — все числа ≥ 1, наименьшая из них равна 1. Принадлежать множеству sup не обязан.
